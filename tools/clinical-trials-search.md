# ClinicalTrials.gov search as flat data

**Use case:** a researcher, analyst or biotech watcher wants every Phase 3 trial for a condition, or everything a sponsor is running, as a table. This Actor queries the official NLM API and returns sponsor, phases, enrollment, dates, interventions, outcomes and countries per trial. Personal contact details are left out.
